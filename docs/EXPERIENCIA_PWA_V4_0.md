# V4.0 — Experiência Mobile/PWA

- Service Worker com cache do shell e fallback offline.
- Banner de estado offline; movimentações não são enfileiradas automaticamente.
- Prompt de instalação PWA quando o navegador disponibilizar.
- Navegação inferior mobile com acesso rápido a Início, Lançamentos, Agenda e Mais.
- Botão de novo lançamento em destaque no mobile/desktop.
- Atalhos do topo passam a abrir Lançamentos e Agenda.
- Mantida a regra: ações financeiras dependem de confirmação explícita.
