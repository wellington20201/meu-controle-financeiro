# Meu Controle Financeiro — V3.0 Inteligência Financeira

A V3.0 adiciona uma camada de inteligência explicável e não-autônoma.

## Princípios
- Projeções são estimativas, não garantias.
- O sistema informa e sugere; não cria compromissos financeiros sem confirmação explícita.
- Transferências internas não entram como receita/despesa econômica.
- Padrões são derivados de dados já registrados pelo usuário.
- Sinais de categoria são apresentados como contexto, não como julgamento.

## Recursos
- Projeção do resultado do mês baseada no ritmo atual.
- Projeção de saldo para os próximos 30 dias usando compromissos previstos e média recente.
- Médias mensais recentes de entradas e saídas.
- Taxa de relação entradas/saídas no mês atual.
- Sinais de categorias acima da média recente.
- Continuidade da memória financeira e sugestões de recorrência.

## Limitações
As projeções não consideram eventos futuros que não estejam registrados no sistema. Antes de usar o produto em decisões relevantes, o usuário deve revisar os lançamentos e compromissos previstos.
