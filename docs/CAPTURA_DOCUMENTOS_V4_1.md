# V4.1 — Captura inteligente de documentos

Permite anexar PDF/JPG/PNG/WEBP a pagamentos recorrentes e fazer uma pré-análise segura. PDFs com texto podem ter valores e datas identificados por heurística. Imagens ficam como aguardando OCR até integração específica. Nenhum lançamento é criado automaticamente; qualquer efeito financeiro continua dependendo de confirmação explícita.
