# Meu Controle Financeiro — V4.7

## Análise Financeira Ampla

O assistente agora interpreta consultas sobre períodos, categorias, fluxo financeiro, patrimônio, metas, compromissos, cartões e dívidas usando somente dados registrados pelo usuário.

### Princípios
- Registro: dado informado pelo usuário.
- Cálculo: resultado derivado dos registros.
- Sugestão: interpretação auxiliar, nunca ordem financeira.
- Nenhuma integração bancária, Open Finance, pagamento, transferência ou operação financeira.
- Dados ausentes são informados como ausência; o assistente não inventa valores.
