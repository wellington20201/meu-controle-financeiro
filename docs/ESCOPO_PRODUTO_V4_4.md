# Escopo do produto — V4.4

## Princípio central
**Meu Controle Financeiro é exclusivamente um sistema de controle, registro, análise e planejamento de gastos e vida financeira.**

Ele não é banco, carteira digital, gateway de pagamento ou agregador bancário.

## Fora do escopo
- conexão com contas bancárias;
- Open Finance;
- leitura de saldo bancário real;
- PIX, TED ou transferências reais;
- execução de pagamentos;
- contratação de produtos financeiros;
- movimentação automática de dinheiro;
- envio de ordens para instituições financeiras.

## O que o produto pode fazer
- registrar manualmente receitas e despesas;
- registrar que uma despesa já foi paga;
- organizar contas internas/virtuais criadas pelo usuário, sem conexão bancária;
- registrar cartões e compras como controle manual;
- acompanhar metas, investimentos e dívidas como informação declarada pelo usuário;
- analisar documentos;
- gerar relatórios e projeções;
- sugerir categorias e padrões;
- responder perguntas financeiras usando os dados do próprio usuário.

## Regra para o assistente
O assistente é **somente leitura e análise por padrão**. Ele pode consultar, calcular, explicar, comparar e simular.

Qualquer alteração de dado exige uma ação explícita do usuário na interface. Nenhuma resposta conversacional pode executar pagamento, transferência ou conexão bancária.

## Terminologia
Para evitar confusão, a interface deve usar **“Marcar como pago”** quando estiver apenas registrando uma despesa que o usuário já pagou. Isso não significa que o aplicativo tenha realizado o pagamento.
