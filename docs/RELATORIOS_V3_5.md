# Relatórios V3.6

A V3.6 adiciona uma visão financeira consolidada sem criar movimentações.

## Dados
- tendência mensal de entradas, saídas e resultado;
- despesas por categoria nos últimos 12 meses;
- saldo atual por conta;
- comprometimento de cartões;
- progresso das metas;
- indicadores do mês atual.

## Exportação
- `Salvar PDF` usa a impressão segura do navegador para salvar a página como PDF;
- `Exportar Excel` gera CSV compatível com Excel, preservando separador e UTF-8.

## Regras
- transferências não entram como receita/despesa econômica;
- relatórios são somente leitura;
- nenhuma exportação altera dados financeiros;
- dados retornados pertencem exclusivamente ao usuário autenticado.
